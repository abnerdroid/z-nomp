# z-nomp

z-nomp is mining pool software for Zcash and Zclassic so you can create internet money in your home!

## Features

- written in JavaScript
- simple installation from releases
- open source

## Installation

Download a release or build from source (JavaScript).

## Usage

```
z-nomp --help
```
